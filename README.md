# USJ Lens PWA

個人利用向けに、USJで確認したい情報を1画面にまとめたPWAです。

## 実装済み
- リアルタイム待ち時間（5分ごと自動更新）
- アトラクション検索、待ち時間が長い順 / 短い順 / 名前順
- 営業中アトラクションの現在平均待ち時間
- 過去平均：時間別 / 日付別 / 月別 / 年別
- アプリ作成前を含む Queue-Times 公開履歴（年選択は2014年〜現在）
- USJ公式のオープン時刻 / クローズ時刻
- ショー / パレード / ステージ / ストリートショーの開始時刻
- 実開園情報：第三者の当日実績が確認できる場合は「報告実績」と明示
- 実績未確認時：第三者の開園予想、または開園直前にPWAが検知した待ち時間データからの推定を別表示
- iPhoneの「ホーム画面に追加」に対応
- オフライン時はアプリ本体と直近取得済みデータをキャッシュ表示

## データ元
- リアルタイム待ち時間・過去統計: Queue-Times.com
- 公式営業時間・ショースケジュール: Universal Studios Japan 公式サイト
- 実開園報告・開園予想: ユニバリアル（USJ非公式の第三者サイト）

USJは予定より早く入場を開始する場合があると案内していますが、実際の一般入場開始時刻を公式の確定データとして配信しているわけではありません。そのため、アプリ内では公式営業時間と第三者の実績/予想/推定を明確に分けています。

## Vercelで公開する場合
1. このフォルダをプロジェクトとして取り込む
2. Framework Preset: `Other`
3. Build Command / Output Directory は基本的に変更しない
4. `Deploy`
5. 発行された HTTPS URL を iPhone の Safari で開く
6. 共有 → `ホーム画面に追加`

`api/` はVercel Serverless Functionsとして動作します。ブラウザから外部サイトへ直接アクセスせず、サーバー側で取得するためCORSの影響を避けます。

## 注意
- ショースケジュールはUSJ公式側でまだ公開されていない日付では表示できません。
- 外部サイトのHTML構造が変わった場合は、`api/history.js` や `api/usj.js` の抽出処理を調整する必要があります。
- 実開園の「報告実績」はUSJ公式値ではありません。
